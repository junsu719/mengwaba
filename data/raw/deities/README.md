## 一、honorific_source / honorific_note 的處理原則

不再套用「萬壽=三清道祖、玉皇上帝;聖誕=自然神;千秋=凡人受封人格神;佛辰=佛教菩薩」
這組分類規則。改為:`honorific_source` 填最高優先序來源(主祀廟官網 > 通行千秋表/
政府機關 > 其他)實際使用的原文用詞;其餘來源用詞不同時,全部記在 `honorific_note`。

## 五、收錄判準

2026-09-19 因開臺聖王正月十六一案(見上方說明)訂立以下判準,回溯套用於本表所有
項目,日後新查證項目一律依此判斷是否收錄進 `deity_birthdays.csv`:

1. **三個來源必須是同一性質的事實陳述,不可互相佐證不同性質的紀錄。** 誕辰要對
   誕辰——祭典日期、輪值日期、紀念日,即使日期剛好相符或相近,也不能拿來佐證
   誕辰,因為兩者記錄的是不同的事實(廟方逕自宣告「這天是神明生日」,和「這天
   歷史上曾是輪值祭祀的起始日」是兩件不同的事)。開臺聖王正月十六正是此例:前
   兩源是廟方生日宣告,第三源是輪值祭典背景資料,性質不同,不算三源一致。
2. **同一尊神明在查證過程中若出現多個不同候選日期,視為共識不存在,不予收錄。**
   即使個別候選日期各自都能找到 1-2 個來源,只要同一位神明的候選日期彼此不
   收斂(本例是正月十六、7/24、8/18 三個候選並存),就代表這尊神明的誕辰在
   現有可查證的公開來源之間本來就沒有共識,不應該由查證者主觀選一個「看起來
   信心較高」的候選收錄進主表。
3. **結構性無單一日期,與查證不足,是兩種不同的不予收錄,需分開記錄。** 城隍爺、
   五府千歲已個別查證總廟(或位階最高的城隍廟)官網確認:城隍信仰依受敕封的
   歷史人物而異、五府千歲五位王爺各自獨立生日且不同廟記載互相矛盾,這是神明
   本身的信仰結構就沒有全國統一單一日期,不是「還沒查到」,屬於**永久性**
   不收錄,不會因為未來查到更多來源而改變結論;開臺聖王、財神/五路財神等則是
   **查證不足或共識不存在**,屬於未來若出現更高品質來源(例如主祀廟官網明確
   公告)仍可能改列入主表的情況。兩者在 `unverified.csv` 的 note 欄位皆已註明
   屬於哪一種。

## 六、王母娘娘與瑤池金母查證報告

**問題**:主表原有瑤池金母、王母娘娘各一行,同為七月十八聖誕,疑似重複收錄同一
神明。2026-09-19 依收錄判準的三源交叉標準重新查證兩者關係。

**結論:確認為同一神明的不同稱呼,非重複收錄**。原本的兩行已合併為一行
(`deity_name=瑤池金母`,`common_name=王母娘娘`)。

**查證來源**(三源):

1. 內政部宗教知識+「瑤池金母」條目(政府來源):
   <https://religion.moi.gov.tw/Knowledge/Content?ci=2&cid=270>
   原文:「瑤池金母又稱為『王母娘娘』、『金母娘娘』、『金母』、『無極瑤池王母』、
   『西王母』」。
2. 維基百科「花蓮勝安宮」條目:
   <https://zh.wikipedia.org/zh-tw/花蓮勝安宮>
   原文:「1950 年起台灣王母娘娘信仰分為兩個系統,分別是『勝安宮』系統和
   『慈惠堂』系統」「『勝安宮』系統恭稱為『天上王母娘娘』,而『慈惠堂』系統則
   尊稱『瑤池西王金母』或『金母娘娘』」。
3. 中華道教傳媒/Yahoo 新聞「慈惠堂總堂」相關報導(轉引慈惠堂系統自述):
   慈惠堂總堂(花蓮吉安,建於民國 39 年)主祀瑤池金母,俗稱西王母、王母娘娘;
   西王金母聖號於民國 38-39 年間一分為二,「瑤池金母」由慈惠堂系統發展、
   「王母娘娘」由勝安宮系統發展,兩廟原為同一信眾分出,僅一牆之隔。

**判斷依據**:三個獨立來源(政府宗教知識資料庫、維基百科、宮廟歷史報導)一致
指出瑤池金母、王母娘娘、西王母是同一神格(統稱「西王金母」)在 1949-1950 年
因信眾分廟(勝安宮/慈惠堂)而產生的兩種稱呼分化,不是兩位不同的神明碰巧同一天
聖誕。依「優先採用主祀該神明的廟宇官方說法」原則,曾嘗試直接查證花蓮勝安宮官網
(sheng-an.org.tw)原文,但該站憑證異常無法連線;慈惠堂總堂目前查無官方網站。
故三源改採政府宗教知識資料庫 + 維基百科 + 宮廟歷史報導的組合,皆為可獨立查核、
非彼此轉載的來源。

**正式名稱的選擇**:兩個名稱在各來源中並列使用,無一方壓倒性常用,但(1)政府
宗教知識資料庫以「瑤池金母」建立主條目(而非「王母娘娘」),(2)慈惠堂系統
(主祀瑤池金母)規模與分堂數量明顯大於勝安宮系統(主祀王母娘娘),故本次以
「瑤池金母」為正式 `deity_name`,「王母娘娘」列為 `common_name`。

**與 unverified.csv 的關聯**:`unverified.csv` 裡另有瑤池金母/王母娘娘三月初三
候選(2 個獨立來源,未達三源)維持原狀不動,該行 `deity_name` 仍分別寫作
「瑤池金母」與「王母娘娘」兩行,本次合併僅處理主表七月十八這組重複,未回溯調整
`unverified.csv`。
